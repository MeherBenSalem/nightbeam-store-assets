# NightBeam store assets

Images used by the NightBeam Studio resource pages on BuiltByBit, one folder per product. The pages load them
directly from this repository, so keep file names stable: renaming or deleting a file breaks the image on the page.

## The NightBeam house template

Every product uses the same template, so the pages read as one studio:

- `hero.png` (1800x600, top of the description) and `cover.png` (2000x1000, the 2:1 listing cover): the product's
  pixel emblem under a single beam of light in the product colour, the product name in Instrument Serif, one line in
  spaced capitals saying what it is, and the NB mark with NIGHTBEAM STUDIO in Monocraft. Nothing else.
- `rule.png`: the divider. `title-*.png`: one section header per description section.
- Background `#0e0d0b`, text `#f4f2ed`, the same as nightbeam.dev. Only the beam colour and the emblem change.
- Numbered `*.jpg` files are the product's feature slides from its marketing kit.

`banner.png`, `divider.png` and `header-*.png` are the previous style, kept until every page uses the new files.

Everything here is a code render, a real in-game capture or typography. No AI image generators were used.
