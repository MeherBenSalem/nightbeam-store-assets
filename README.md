# NightBeam store assets

Images used by the NightBeam Studio resource pages on BuiltByBit, one folder per product. The pages load them
directly from this repository, so keep file names stable: renaming or deleting a file breaks the image on the page.

## The NightBeam house template

Every product uses the same template, so the pages read as one studio and only the colour and the icon change:

- `hero.png` (1800x600, top of the description) and `cover.png` (2000x1000, the 2:1 listing cover): a dark panel with
  cut corners inside a frame in the product colour, a beam of light onto one flat icon, the product name in Russo One
  with a two-tone extruded face, one ribbon line saying what it is, and the NB badge with NIGHTBEAM.
- `rule.png`: the divider. `title-*.png`: one section title per description section, in the same type.
- Icons: Phosphor Icons (MIT licence). Title font: Russo One (SIL Open Font Licence). Badge: the NightBeam NB mark.
- Numbered `*.jpg` files are the product's feature slides from its marketing kit.

`banner.png`, `divider.png` and `header-*.png` are the previous style, kept until every page uses the new files.

Everything here is a code render, a real in-game capture or typography. No AI image generators were used.
